# deep-os-demo-videos

架空データのみを使ったDEEP OSのデモ動画。本番環境・実データは含みません。

## 動画を見る

動画ファイルは [GitHub Releases](https://github.com/OMrice8383/deep-os-demo-videos/releases) にあります。

- [卓管理デモ（JARVIS-G3-T46）](https://github.com/OMrice8383/deep-os-demo-videos/releases/tag/jarvis-g3-t46)：35.9秒、縦720×1280、無音のMP4。
- 卓管理トップ → 入卓 → セット終了時刻の自動表示 → 入卓記録の確認 → 卓を空きに戻す、までを収録しています。**POS会計連動は含みません。**

収録範囲の根拠は上記Releaseの説明です。最新の実装状況や受入状況は、動画ではなく担当RepoとPMのTaskで確認してください。
